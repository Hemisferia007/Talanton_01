# Skills del proyecto

Skills de terceros instaladas a nivel proyecto (no en `~/.claude/skills`) para que
viajen con el repo y las tenga todo el equipo.

| Skill | Para qué | Origen |
|---|---|---|
| `craft` | 12 reglas de craft visual sobre CSS/UI: prohibiciones (gradientes, glow, `transition: all`) y disciplinas de espaciado, tipografía, elevación, estados y motion. | [tommyjepsen/awesome-ux-skills](https://github.com/tommyjepsen/awesome-ux-skills) |
| `accessibility` | Revisión WCAG 2.1 A/AA de pantallas y flujos. | [tommyjepsen/awesome-ux-skills](https://github.com/tommyjepsen/awesome-ux-skills) |

El repo de origen trae más skills (`general-design-review`, `ux-heuristics-review`,
`cognitive-load-conversion`, `dieter-rams-principles`, entre otras). Se instalan
copiando el `.md` correspondiente a `.claude/skills/<nombre>/SKILL.md`.
